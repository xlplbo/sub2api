## 恢复的行为

- `passthrough` 上游拨号发生未收到 HTTP 状态码的传输错误时，沿用原有拨号错误处理并向客户端报错，不通过该入口重新选择账号。

- 客户端需要自行处理连接失败及会话恢复；网关不会在此路径尝试重建历史。
